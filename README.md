# ⚽ STRIKER HUB - ร้านอุปกรณ์กีฬาฟุตบอลของแท้ระดับพรีเมียม

เว็บไซต์ร้านค้าออนไลน์ (E-Commerce) จำหน่ายอุปกรณ์กีฬาฟุตบอลครบวงจร พัฒนาด้วยเทคโนโลยี Modern Web (HTML5, Tailwind CSS, Vanilla JavaScript, Lucide Icons) ไม่ต้องติดตั้ง Node.js หรือ Environment ใดๆ สามารถเปิดใช้งานได้ทันทีบนทุกเบราว์เซอร์

---

## 🌟 ฟีเจอร์เด่นของเว็บไซต์ (Key Features)

1. **หน้าร้านและแคตตาล็อกสินค้าครบวงจร**:
   - รองเท้าสตั๊ด (Football Boots) แบรนด์ดัง เช่น Nike Mercurial Superfly 10, Adidas Predator 24, Mizuno Morelia Neo IV (Made in Japan), Puma Future
   - เสื้อแข่งสโมสรและทีมชาติ (Jerseys) เช่น ทีมชาติไทย Changsuek, Real Madrid, Arsenal, Manchester City
   - ลูกฟุตบอลแมตช์เดย์ (Match Balls) ได้รับการรับรอง FIFA Quality Pro (UCL Ball, Premier League Ball, Molten)
   - ถุงมือผู้รักษาประตู (GK Gloves) แบรนด์ Adidas Predator FingerSave, Uhlsport Supergrip+
   - อุปกรณ์ซ้อมและป้องกัน (Gear & Protection) สนับแข้ง Nike Mercurial Lite, ถุงเท้ากันลื่น Tapedesign, กรวยฝึกซ้อม

2. **ระบบค้นหาและตัวกรองอัจฉริยะ (Search & Filter System)**:
   - ค้นหาแบบเรียลไทม์ (Live Search) ตามชื่อสินค้า แบรนด์ และคำบรรยาย
   - กรองตามหมวดหมู่ (Categories)
   - กรองตามแบรนด์ (Nike, Adidas, Puma, Mizuno, Uhlsport, Molten)
   - กรองตามประเภทปุ่มสตั๊ด (FG - หญ้าจริง, AG - หญ้าเทียม, TF - ร้อยปุ่ม)
   - จัดเรียงตาม ราคา (ต่ำ-สูง / สูง-ต่ำ), เรตติ้ง, และสินค้าใหม่

3. **หน้าต่างดูรายละเอียดสเปกสินค้า (Quick View & Product Detail Modal)**:
   - ตารางสเปกอย่างละเอียด (ประเภทปุ่ม, อัปเปอร์, เทคโนโลยี, น้ำหนัก)
   - ตัวเลือกไซส์รองเท้าและเสื้อ
   - **ฟีเจอร์พิเศษ: สกรีนชื่อและเบอร์เสื้อบอลฟรี (Jersey Customizer)** พร้อมระบบพรีวิวชื่อและหมายเลขแบบสดๆ ก่อนกดลงตะกร้า

4. **ตะกร้าสินค้าแบบสไลด์ (Interactive Slide-over Cart)**:
   - ปรับเพิ่ม/ลดจำนวนสินค้า หรือลบสินค้าได้ทันที
   - แถบคำนวณสิทธิ์จัดส่งฟรีแบบไดนามิก (ซื้อครบ ฿2,000 ส่งฟรี)
   - ระบบโค้ดส่วนลด (Promo Codes):
     - `KICKOFF10` (ลด 10%)
     - `STRIKER100` (ส่วนลด ฿100)
     - `FREESHIP` (ฟรีค่าจัดส่ง)

5. **ระบบเช็คเอาท์และจำลองการสั่งซื้อ (Checkout Flow & Order Confirmation)**:
   - ฟอร์มข้อมูลจัดส่ง (ชื่อ, เบอร์โทรศัพท์, ที่อยู่)
   - ตัวเลือกขนส่ง (Flash Express / Kerry / EMS ไปรษณีย์ไทย)
   - ตัวเลือกชำระเงิน (PromptPay QR Code, โอนธนาคาร, เก็บเงินปลายทาง COD)
   - ใบเสร็จสรุปคำสั่งซื้อพร้อมรหัสออเดอร์ (ORD-XXXXXX)

6. **ระบบรายการที่ชอบ (Wishlist)**:
   - บันทึกสินค้าที่ชื่นชอบด้วยการคลิกไอคอนหัวใจ
   - เก็บข้อมูลอัตโนมัติใน LocalStorage แม้ปิดเบราว์เซอร์แล้วเปิดใหม่ข้อมูลก็ยังอยู่

7. **ตารางเทียบไซส์ (Size Guide)**:
   - ตารางเทียบไซส์รองเท้าสตั๊ด JP/CM, US, UK, EUR
   - ตารางขนาดรอบอกและความยาวเสื้อแข่ง S, M, L, XL, 2XL

## 🚀 วิธีเปิดใช้งานเว็บไซต์ (How to Run)

### วิธีที่ 1: ดับเบิ้ลคลิกเปิดได้ทันที (แนะนำ)
- ดับเบิ้ลคลิกไฟล์ `start.bat` หรือดับเบิ้ลคลิกไฟล์ `index.html` บนโฟลเดอร์นี้ เว็บไซต์จะเปิดขึ้นมาบนเบราว์เซอร์ (Chrome, Edge ฯลฯ) ทันที

### วิธีที่ 2: รันผ่าน Local Web Server (Python)
หากต้องการรันผ่าน Web Server:
```bash
python -m http.server 8000
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:8000`
